# Nightcast Studio

Nightcast Studio is being built as a local-first character podcast generator.

Live Lovable deployment: https://nightcast-studio.lovable.app

Project editor: https://lovable.dev/projects/23947cbf-e8ed-4657-aedc-09cfcc4c1d79

The app is designed to work without paid APIs for its core features by using browser speech synthesis and local storage.
